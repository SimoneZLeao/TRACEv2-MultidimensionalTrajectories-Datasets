# TRACE-V2: Multidimensional Artistic Career Trajectories — Datasets

## Overview

This repository provides datasets generated and analysed through TRACE-V2 (Trajectory Reconstruction through Agent-based Cultural Emergence), an agent-based model developed to investigate the multidimensional dynamics of artistic careers.

The datasets correspond to **Simulation 1** and provide the original simulation output and the processed artist-level data used in the multidimensional trajectory analysis.

TRACE-V2 is an exploratory computational model. Its results are intended to support the investigation of emergent career patterns under specified model assumptions, rather than to predict the careers of individual artists or represent observed real-world career histories.

## Repository contents

### 1. Original simulation output

**File:** `simulation_data_1.zip`

This compressed archive contains the original CSV file, `simulation_data_1.csv`, with the full simulation output.

- **Artists:** 1,089 artist agents
- **Simulation duration:** 260 weekly ticks per artist
- **Observations:** 283,140 artist-tick records
- **Variables:** 25

The CSV records the original agent-level simulation data across all 260 ticks. To use the dataset, download and extract the ZIP archive.

### 2. Processed artist-level analytical dataset

**File:** `simulation_1_all_variables_all_four_clusters.csv`

This dataset contains the processed artist-level information used in the multidimensional trajectory analysis.

- **Artists:** 1,089 artist records
- **Variables:** 68

It brings together artist-level measures and the trajectory classifications obtained through four separate analytical dimensions:

- Economic capital
- Symbolic capital
- Secondary employment
- Exits

### 3. Supporting documentation

**File:** `TRACE_MultidimensionalAnalysis_Datasets_ReleaseNov2026.pdf`

This document describes the datasets, their variables, the analytical dimensions, and relevant information for interpreting and reusing the data. It should be consulted alongside the CSV files.

## Scope and interpretation

The repository provides the data for **Simulation 1**, not the complete output of all 100 simulations conducted in the TRACE-V2 study. Simulation 1 is presented as an illustrative dataset for examining the model output and the multidimensional trajectory classifications.

The four trajectory classifications represent distinct analytical perspectives. They should not be interpreted as a single integrated or causal classification of artistic careers.
